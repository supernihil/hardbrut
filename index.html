DETAILS / SUMMARY

What is HARDBRUT

An opinionated neubrutalist CSS framework. Every shadow-bearing element keeps its shadow — only gone during a press animation. Auto dark mode via system preference, plus a manual toggle (☀ button in the navbar) that persists to localStorage.

Rules (pre-opened)
  • Zero border-radius — ever
  • Every element has its shadow. Always. Except during press.
  • Two button kinds: default (yellow) + cancel (white)
  • All buttons animate identically
  • Full markdown element coverage
  • Dark mode: auto (system) + manual toggle (persisted)
Size

~16KB uncompressed. ~3.5KB gzipped. Zero webfonts — Impact for display, system stack for body.

BUTTONS

Two kinds. Same size. Same animation. Bare <button> is yellow (default). .cancel for white (dismiss).
