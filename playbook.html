Rules of thumb

  • Reach for .list-row and .chat as-is — don't wrap them in .card, they already carry their own border/shadow.
  • .list-row-title / .list-row-subtitle truncate to one line by design. If you need full text, don't use them — use plain text inside .list-row-body.
  • Selected/toggled state always means "filled with --accent, text in --accent-ink" — .chip[aria-pressed="true"], .switch:checked, buttons, badges all follow the same rule. Don't invent a second "selected" color.
  • Every shadow-bearing element (.card, .list-row, buttons, chips, switches) keeps its shadow always — it only disappears on :active. Don't strip shadows for a "flatter" look; that's a different framework.

Typography

h1–h6
Uppercase, display font, auto-scaling via clamp() on h1–h3. <h2>Title</h2>
strong / b, em / i
Bold and italic — either tag works, same rule.
del / s, u / ins
Strikethrough and underline — either tag in each pair works.
mark
Accent-color highlight. <mark>highlighted</mark>
small, sub, sup
Smaller text, subscript, superscript — standard semantics.
abbr[title]
Dotted underline, native tooltip. <abbr title="Cascading Style Sheets">CSS</abbr>
code, kbd, samp
Inline mono with a border — code, keyboard input, program output. All three look identical, semantics differ.
pre
Bordered, shadowed, horizontally scrollable code block. Wrap a <code> inside for syntax-block styling.
blockquote
6px left border, italic. For pull quotes.
hr
Full-width rule, thick border color.
figure / figcaption
Wraps an img (already bordered+shadowed) with a muted caption below.
ul, ol, dl
Standard lists, nested lists supported. dl/dt/dd for term/definition pairs — this reference is one.
table
Bordered, striped rows, header row inverted (ink bg). Scrolls horizontally on its own if too wide — never forces the page to.

Layout

.container
Max-width 1100px, centered, side padding. Wrap your page content in one.
.section
Vertical padding block — one per page section.
.grid + .col-1….col-12
12-column grid. 6-col at 768px, 1-col at 480px, automatically.
.stack
Flex column with gap — vertical stacking.
.cluster
Flex row, wraps, with gap — the pattern behind every button row on this page.

Interactive: tabs & dialog

Both shown live under Elements. Minimal wiring:

<div class="tab-list" role="tablist">
  <button class="tab" role="tab" aria-selected="true"
    aria-controls="panel-a" id="tab-a" onclick="hbSelectTab(this,'panel-a')">One</button>
  <button class="tab" role="tab" aria-selected="false"
    aria-controls="panel-b" id="tab-b" onclick="hbSelectTab(this,'panel-b')">Two</button>
</div>
<div class="tab-panel" role="tabpanel" id="panel-a" aria-labelledby="tab-a">...</div>
<div class="tab-panel" role="tabpanel" id="panel-b" aria-labelledby="tab-b" hidden>...</div>

<script>
function hbSelectTab(btn, panelId){
  btn.closest('.tab-list').querySelectorAll('.tab').forEach(function(t){
    t.setAttribute('aria-selected', String(t === btn));
    var panel = document.getElementById(t.getAttribute('aria-controls'));
    if (panel) panel.hidden = (panel.id !== panelId);
  });
}
</script>

ANDROID

Same rules, Jetpack Compose. For the full composable list and token mapping, see Android on the main site.

Setup

// 1. Drop Hardbrut.kt into your project (one file, one dependency: Compose)
// 2. Pick an accent pair
val (accent, accentInk) = HardbrutTokens.AccentYellow

Compose has no CSS-like text-transform — every composable that takes a raw String (badge, chip, list row) uppercases it internally. If you build custom content with Text() yourself (e.g. inside HardbrutButton), uppercase the label at the call site.

Recipe: primary + cancel buttons

val (accent, accentInk) = HardbrutTokens.AccentYellow

Row(horizontalArrangement = Arrangement.spacedBy(HardbrutTokens.SpaceSm)) {
    HardbrutButton(onClick = { /* save */ }, accent = accent, accentInk = accentInk) {
        Text("SAVE")
    }
    HardbrutButton(
        onClick = { /* dismiss */ },
        accent = accent, accentInk = accentInk,
        kind = ButtonKind.Cancel
    ) { Text("CANCEL") }
}

Recipe: conversation list

HardbrutListRow mirrors the CSS .list-row — avatar, title, subtitle (single-line, ellipsized), and a trailing slot for a timestamp or badge.

LazyColumn(verticalArrangement = Arrangement.spacedBy(HardbrutTokens.SpaceSm)) {
    items(threads) { thread ->
        HardbrutListRow(
            title = thread.name,
            subtitle = thread.lastMessage,
            avatarText = thread.initials,
            onClick = { openThread(thread.id) },
            trailing = {
                Column(horizontalAlignment = Alignment.End) {
                    Text(thread.time, fontSize = 12.sp, color = HardbrutTokens.Muted)
                    if (thread.unread > 0) {
                        HardbrutBadge(thread.unread.toString())
                    }
                }
            }
        )
    }
}

Recipe: settings screen

Switches and chips read the same accent pair as everything else — pass it down once.

val (accent, accentInk) = HardbrutTokens.AccentYellow
var emailOn by remember { mutableStateOf(true) }
var digestOn by remember { mutableStateOf(false) }
var mutedTopic by remember { mutableStateOf<String?>(null) }

HardbrutCard {
    Text("NOTIFICATIONS", fontWeight = FontWeight.ExtraBold)
    Spacer(Modifier.height(HardbrutTokens.SpaceSm))
    Row(verticalAlignment = Alignment.CenterVertically) {
        HardbrutSwitch(emailOn, { emailOn = it }, accent, accentInk)
        Spacer(Modifier.width(8.dp))
        Text("Email me about replies")
    }
    Spacer(Modifier.height(HardbrutTokens.SpaceSm))
    Row(horizontalArrangement = Arrangement.spacedBy(8.dp)) {
        HardbrutChip("Billing", selected = mutedTopic == "billing",
            onClick = { mutedTopic = "billing" }, accent = accent, accentInk = accentInk)
        HardbrutChip("Marketing", selected = mutedTopic == "marketing",
            onClick = { mutedTopic = "marketing" }, accent = accent, accentInk = accentInk)
    }
}

Dark mode

Hardbrut.kt ships light-only tokens today — there's no HardbrutTokens dark variant yet. If your app supports dark mode, branch on isSystemInDarkTheme() and swap the three theme-dependent tokens, mirroring the CSS [data-theme="dark"] block:

val isDark = isSystemInDarkTheme()
val ink = if (isDark) Color(0xFFF0F0E8) else HardbrutTokens.Ink
val paper = if (isDark) Color(0xFF1A1A18) else HardbrutTokens.Paper
val background = if (isDark) Color(0xFF121210) else HardbrutTokens.Background
// accent / accentInk stay the same in both themes — same as the web version

Every composable takes accent/accentInk as parameters rather than reading a global, so swapping ink/paper/background at the call site is enough — nothing internal needs to change.

Rules of thumb

  • Every composable takes accent/accentInk explicitly — there's no global theme object to reach for. Pick a HardbrutTokens.Accent* pair once per screen and thread it through.
  • HardbrutButton uses a custom black-15%-alpha ripple, not the platform default — don't override indication yourself unless you're deliberately deviating from the spec in ANDROID.md.
  • Android's Modifier.shadow() can't do zero blur — every HARDBRUT composable uses Modifier.hardShadow() instead (drawn as a flat offset rect). Don't mix in Modifier.shadow(); the blur will look inconsistent next to everything else.
  • HardbrutTabRow and HardbrutDialog only handle chrome — panel switching (tabs) and dismiss wiring (dialog) are yours, same division of labor as the CSS versions. No dedicated segmented-progress composable yet; build your own row of filled/unfilled Boxes if you need one.

Reference: every composable, in one place

Signatures live under Android → All composables — this is the usage version, one minimal call per composable.

val (accent, accentInk) = HardbrutTokens.AccentYellow

// Button — two kinds, same call either way
HardbrutButton(onClick = {}, accent = accent, accentInk = accentInk) { Text("SAVE") }
HardbrutButton(onClick = {}, accent = accent, accentInk = accentInk,
    kind = ButtonKind.Cancel) { Text("CANCEL") }

// Card
HardbrutCard { Text("Card content") }

// Text field
var name by remember { mutableStateOf("") }
HardbrutTextField(value = name, onValueChange = { name = it },
    label = "Name", placeholder = "Your name")

// Checkbox / radio / switch
var checked by remember { mutableStateOf(false) }
HardbrutCheckbox(checked = checked, onCheckedChange = { checked = it })
HardbrutRadio(selected = checked, onClick = { checked = true })
HardbrutSwitch(checked = checked, onCheckedChange = { checked = it },
    accent = accent, accentInk = accentInk)

// Badge / chip / callout
HardbrutBadge("3", accent = accent, accentInk = accentInk)
HardbrutChip("Open", selected = true, onClick = {}, accent = accent, accentInk = accentInk)
HardbrutCallout("Heads up — this can't be undone.", accent = accent, accentInk = accentInk)

// List row — see the conversation-list recipe above for the full version
HardbrutListRow(title = "Jane Doe", subtitle = "Let's ship it Thursday",
    avatarText = "JD", onClick = { })

// Tabs — panel switching is a plain when/if, same as CSS leaves [hidden] to you
var tab by remember { mutableStateOf(0) }
HardbrutTabRow(tabs = listOf("Overview", "Details"), selected = tab,
    onSelect = { tab = it }, accent = accent, accentInk = accentInk)
when (tab) {
    0 -> Text("Overview panel")
    1 -> Text("Details panel")
}

// Dialog
var showDialog by remember { mutableStateOf(false) }
if (showDialog) {
    HardbrutDialog(onDismissRequest = { showDialog = false }) {
        Text("Delete conversation?", fontWeight = FontWeight.ExtraBold)
        Spacer(Modifier.height(HardbrutTokens.SpaceSm))
        HardbrutButton(onClick = { showDialog = false },
            accent = accent, accentInk = accentInk) { Text("DELETE") }
    }
}

// Details (expandable) — Compose has no <details>, state is yours
var expanded by remember { mutableStateOf(false) }
HardbrutDetails(summary = "What is HARDBRUT", expanded = expanded,
    onToggle = { expanded = !expanded }) { Text("An opinionated design system.") }
