What

HARDBRUT is a tiny, opinionated CSS framework in the neubrutalist style. Zero border-radius. Hard shadows (5px 5px 0, no blur). Thick 3px borders. Bold uppercase typography. Full coverage of every HTML element from markdown.

Rules

  • Zero border-radius — ever
  • Every shadow stays. Only gone during a press animation
  • Two button kinds: default + cancel
  • All buttons animate identically — and are all the same height
  • 6 accent colors to choose from
  • Dark mode: auto (system) + manual toggle (persists)
