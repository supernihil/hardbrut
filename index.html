START

What

HARDBRUT is a tiny, opinionated CSS framework in the neubrutalist style. Zero border-radius. Hard shadows (5px 5px 0, no blur). Thick 3px borders. Bold uppercase typography. Full coverage of every HTML element from markdown.

Rules

  • Zero border-radius — ever
  • Every shadow stays. Only gone during a press animation
  • Two button kinds: default + cancel
  • All buttons animate identically — and are all the same height
  • 6 accent colors to choose from
  • Dark mode: auto (system) + manual toggle (persists)

Theme toggle

Sets data-theme on <html>. The button glyph flips with it, so it always shows the mode you'd switch to.

<button class="theme-toggle" onclick="toggleTheme()">☾</button>
<script>
(function(){
  var h = document.documentElement;
  var t = localStorage.getItem('theme');
  if (!t) t = window.matchMedia('(prefers-color-scheme:dark)').matches ? 'dark' : 'light';
  h.setAttribute('data-theme', t);
  function updateToggle(){
    var btn = document.querySelector('.theme-toggle');
    var isDark = h.getAttribute('data-theme') === 'dark';
    btn.textContent = isDark ? '☀' : '☾';
  }
  window.toggleTheme = function(){
    var cur = h.getAttribute('data-theme') === 'dark' ? 'light' : 'dark';
    h.setAttribute('data-theme', cur);
    localStorage.setItem('theme', cur);
    updateToggle();
  };
  window.addEventListener('DOMContentLoaded', updateToggle);
})();
</script>

Hard shadow helper

fun Modifier.hardShadow(size: Dp, color: Color = Color.Black): Modifier = this.then(
    drawBehind {
        drawRect(color = color, topLeft = Offset(size.toPx(), size.toPx()),
            size = Size(this.size.width, this.size.height))
    }
)
