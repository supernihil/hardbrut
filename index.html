ABOUT

What

HARDBRUT is a tiny, opinionated CSS framework in the neubrutalist style. Zero border-radius. Hard shadows (5px 5px 0, no blur). Thick 3px borders. Bold uppercase typography. Full coverage of every HTML element that comes out of a markdown renderer.

Rules

  • Zero border-radius — ever
  • Every shadow stays. Only gone during a press animation
  • Two button kinds: default + cancel
  • All buttons animate identically
  • 6 accent colors to choose from (pick one)
  • Dark mode: auto (system) + manual toggle (persists)

Size

~18KB uncompressed. ~3.5KB gzipped. Zero webfonts needed (Inter via Google Fonts). Impact/display fonts removed — everything uses Inter at different weights. No build step. One file. Drop it in and go.

Hard shadow helper

Android Modifier.shadow() does not support zero blur radius. Use this extension to draw a perfectly hard shadow:

fun Modifier.hardShadow(size: Dp, color: Color = Color.Black): Modifier = this.then(
    drawBehind {
        drawRect(
            color = color,
            topLeft = Offset(size.toPx(), size.toPx()),
            size = Size(this.size.width, this.size.height)
        )
    }
)
// Usage: Modifier.hardShadow(5.dp)

Buttons

@Composable
fun HardbrutButton(
    onClick: () -> Unit,
    accent: Color,
    accentInk: Color,
    kind: ButtonKind = ButtonKind.Default,
    enabled: Boolean = true,
    content: @Composable RowScope.() -> Unit
) {
    val shadowDp = when (kind) {
        ButtonKind.Default -> 5.dp
        ButtonKind.Cancel -> 3.dp
    }
    val bg = when (kind) {
        ButtonKind.Default -> accent
        ButtonKind.Cancel -> Color.White
    }
    val fg = when (kind) {
        ButtonKind.Default -> accentInk
        ButtonKind.Cancel -> Color.Black
    }
    Row(
        modifier = Modifier
            .hardShadow(shadowDp)
            .border(3.dp, Color.Black)
            .background(bg)
            .clickable(enabled = enabled) { onClick() }
            .padding(horizontal = 24.dp, vertical = 12.dp),
        horizontalArrangement = Arrangement.Center,
        verticalAlignment = Alignment.CenterVertically
    ) {
        ProvideTextStyle(TextStyle(
            fontWeight = FontWeight.ExtraBold,
            fontSize = 15.sp,
            textTransform = TextTransform.Uppercase,
            letterSpacing = 0.3.sp,
            color = fg
        )) { content() }
    }
}
enum class ButtonKind { Default, Cancel }

Cards

@Composable
fun HardbrutCard(
    modifier: Modifier = Modifier,
    content: @Composable ColumnScope.() -> Unit
) {
    Column(
        modifier = modifier
            .hardShadow(5.dp)
            .border(3.dp, Color.Black)
            .background(Color.White)
            .padding(24.dp)
    ) { content() }
}

Inputs

Always carry a shadow (3dp). Focus moves it to 5dp. Use BasicTextField with a custom Box wrapper.

@Composable
fun HardbrutTextField(
    value: String,
    onValueChange: (String) -> Unit,
    label: String = "",
    placeholder: String = ""
) {
    var focused by remember { mutableStateOf(false) }
    Column {
        if (label.isNotEmpty()) Text(label.uppercase(),
            fontWeight = FontWeight.ExtraBold,
            fontSize = 13.sp, letterSpacing = 0.4.sp)
        BasicTextField(
            value, onValueChange,
            modifier = Modifier
                .hardShadow(if (focused) 5.dp else 3.dp)
                .border(3.dp, Color.Black)
                .background(Color.White)
                .onFocusChanged { focused = it.isFocused }
                .padding(horizontal = 14.dp, vertical = 11.dp)
                .heightIn(min = 46.dp),
            decorationBox = { inner ->
                if (value.isEmpty()) Text(placeholder, color = Color.Gray)
                inner()
            }
        )
    }
}

Badge / Callout

@Composable
fun HardbrutBadge(text: String, accent: Color, accentInk: Color) {
    Text(text.uppercase(),
        fontFamily = FontFamily.Monospace,
        fontSize = 12.sp, letterSpacing = 0.6.sp,
        color = accentInk,
        modifier = Modifier
            .hardShadow(3.dp)
            .border(2.dp, Color.Black)
            .background(accent)
            .padding(horizontal = 10.dp, vertical = 3.dp)
    )
}

Spacing

All spacing is one of: 12dp (tight), 24dp (normal), 40dp (wide). Never use arbitrary values.

Accent colors

Set data-accent on <html> to one of: yellow, red, blue, green, pink, purple. Default is yellow.

Theme toggle

Add this script for a manual dark mode toggle (persists to localStorage):

<script>
(function(){
  var h = document.documentElement;
  var t = localStorage.getItem('theme');
  if (!t) t = window.matchMedia('(prefers-color-scheme:dark)').matches ? 'dark' : 'light';
  h.setAttribute('data-theme', t);
  window.toggleTheme = function(){
    var cur = h.getAttribute('data-theme') === 'dark' ? 'light' : 'dark';
    h.setAttribute('data-theme', cur);
    localStorage.setItem('theme', cur);
  };
})();
</script>
<button class="theme-toggle" onclick="toggleTheme()">☀</button>
