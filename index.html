What

HARDBRUT is a tiny, opinionated CSS framework in the neubrutalist style. Zero border-radius. Hard shadows (5px 5px 0, no blur). Thick 3px borders. Bold uppercase typography. Full coverage of every HTML element from markdown.

Rules

  • Zero border-radius — ever
  • Every shadow stays. Only gone during a press animation
  • Two button kinds: default + cancel
  • All buttons animate identically — and are all the same height
  • 6 accent colors to choose from
  • Dark mode: auto (system) + manual toggle (persists)

Get it

CSS — drop it in. Zero build step. Font embedded inline.

<link rel="stylesheet" href="https://supernihil.github.io/hardbrut/hardbrut.css">
hardbrut.css (53KB, with font) hardbrut.min.css (50KB, minified)

The font (Inter 900, latin subset) is embedded as base64 — ~31KB of the total (23.9KB of binary font inflates to base64 text). CSS rules alone: ~21KB unminified, ~18KB minified — that's exactly what hardbrut.nofont.css below is. Once loaded, the file makes zero further network requests: no @import, no Google Fonts, no CDN.

Don't want the font? hardbrut.nofont.css (21KB) — same rules, system font stack only. Its own .min.css is ~19KB; minification only meaningfully shrinks the rules, since the embedded font is already binary and can't shrink further.

Quick start

<!DOCTYPE html>
<html lang="en" data-accent="yellow">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link rel="stylesheet" href="hardbrut.css">
</head>
<body>
  <nav class="navbar">
    <a href="./" class="navbar-brand">Site</a>
    <ul class="navbar-links">
      <li><a href="#" aria-current="page">Home</a></li>
    </ul>
  </nav>
  <main class="container">
    <h1>Hello World</h1>
    <p>This is HARDBRUT.</p>
    <button>Click me</button>
  </main>
</body>
</html>

Accent colors

Set data-accent on <html> to: yellow, red, blue, green, pink, purple. Default is yellow.

Theme toggle

Sets data-theme on <html>. The button glyph flips with it, so it always shows the mode you'd switch to.

<button class="theme-toggle" onclick="toggleTheme()">☾</button>
<script>
(function(){
  var h = document.documentElement;
  var t = localStorage.getItem('theme');
  if (!t) t = window.matchMedia('(prefers-color-scheme:dark)').matches ? 'dark' : 'light';
  h.setAttribute('data-theme', t);
  function updateToggle(){
    var btn = document.querySelector('.theme-toggle');
    var isDark = h.getAttribute('data-theme') === 'dark';
    btn.textContent = isDark ? '☀' : '☾';
  }
  window.toggleTheme = function(){
    var cur = h.getAttribute('data-theme') === 'dark' ? 'light' : 'dark';
    h.setAttribute('data-theme', cur);
    localStorage.setItem('theme', cur);
    updateToggle();
  };
  window.addEventListener('DOMContentLoaded', updateToggle);
})();
</script>

Accent picker

<button class="accent-swatch" data-accent="red" onclick="setAccent('red')"></button>
<script>
window.setAccent = function(c){
  document.documentElement.setAttribute('data-accent', c);
  localStorage.setItem('accent', c);
};
</script>
